2026-08-05（三）｜預估學習時間：90 分鐘｜難度：★★★★☆（本週總整理課——不出新反派，把 via、stub、connector 三天的散裝招式收成一套方法論）
今日目標

Day 9 到 Day 12 你認識了所有反派（via、stub、connector），也零星學了幾招對策（back-drill、掏空、G-S-S-G）。今天換位子——從「判讀者」升級成「開藥方的設計者」。讀完你要能夠：

  1. 背出補償設計的三條公理：面積反推寄生量、配平條件 L = Z₀²C、集總條件（結構要夠短補償才成立）
  2. 拿到任何一張 TDR 曲線先做分診：五種指紋裡，哪三種是「補償可治」、哪兩種是「補償禁忌症」——開錯藥比不開藥更糟
  3. 打開藥方櫃：anti-pad 加大、非功能 pad 移除、back-drill、參考層掏空、pad 瘦身、頸縮漸變、回流 via——每一味藥往哪個方向推（L↑ L↓ C↑ C↓）、劑量怎麼估
  4. 會算補償的頻寬極限：f_c ≈ 1/(π√(LC))——為什麼配平只保證「反射小」、不保證「頻寬夠」；「小而平衡」為何永遠贏「大而平衡」
  5. 知道什麼時候該認輸改架構，並能引用《Perfect Timing II》Ch.6 的原文說明「最好的補償是根本不需要補償」

0. 前情提要：反派集齊，該輪到我們出手了

這一週的劇情線：Day 9 學會「認指紋」（凹陷、尖峰、台階、墊高、扭波）；Day 11 拆了 stub（諧振腔、f₀ = v/4ℓ、t_r/6 門檻）；Day 12 拆了 connector（C–L–C π 模型、配平公式、回流 pin map、掏空補償）。散落三課的工具今天全部上桌，收攏成一張「指紋 → 分診 → 藥方」的對照表——這正是資深 SI 工程師和「會量 TDR 的人」之間的差距：前者看到波形，腦中同時浮現病理與處方。

白話版：TDR 是聽診器，今天教你當醫生

前幾天你學的是「聽診」：心雜音（凹陷）、心律不整（尖峰）、心跳整個變調（台階）。今天學的是醫生的完整流程：分診 → 診斷 → 開藥 → 回診。醫生最重要的能力不是背藥名，而是知道哪些病吃藥會好、哪些病吃藥沒用得開刀——阻抗補償也一樣：有三種指紋是「調一調 L 和 C 就能治」，有兩種指紋是「補償完全無效、必須動結構」。開錯藥（比如對著一段阻抗做錯的走線拚命掏參考層）不但治不好，還會把板子越修越爛。今天的表格就是你的《診斷手冊》。

1. 補償設計的三條公理

所有藥方共用的三條地基，前幾天各出現過一次，今天正式並列。公式看不懂可以先跳過，每條下面的白話翻譯懂了就好。

公理一：面積反推寄生量（Day 9）

L_excess = 2Z₀ × A_尖峰　；　C_excess = (2/Z₀) × A_凹陷　（A 為 TDR 上 ρ 對時間的面積）

白話翻譯：TDR 上尖刺或凹陷的「面積」直接告訴你多了幾 nH 或幾 pF——高度會被儀器邊沿快慢騙，面積不會（Day 9 面積不變性）。這是「診斷書上的數字」：知道欠多少，才知道藥下多重。

公理二：配平條件（Day 12）

Z_local ≈ √(L/C)　→　配平：L = Z₀²·C　（50 Ω 系統：L[nH] = 2.5 × C[pF]）

白話翻譯：補償不是消滅寄生，是調蹺蹺板——每 1 pF 的多餘電容配 2.5 nH 的電感就打平。凹了就減 C 或加 L；尖了就減 L 或加 C。所有藥方都只是「往蹺蹺板的某一端加減砝碼」的不同手段。

公理三：集總條件（Day 11 的 t_r/6 門檻，換個說法）

結構的電氣長度 ℓ ≪ t_r 對應的空間長度（工程門檻：ℓ < 空間長度/6 量級）

白話翻譯：「把 L 和 C 互相抵帳」這件事，只有在整個結構短到訊號邊沿「一眼看不出內部細節」時才成立——邊沿同時罩住整個 C-L-C，三個元件才能合起來扮演一小段 50 Ω 線。結構一旦長到邊沿「走進去還沒走出來」，它就是一段真的錯阻抗傳輸線，配平魔法失效。這條公理決定了第 5 節「補償的極限」。

三公理串成一句話

先用面積算出欠多少（公理一），再用配平算出補多少（公理二），最後檢查結構夠不夠短、補償有沒有資格成立（公理三）。面試白板上把這三步講清楚，補償題就拿下八成分數。

2. 分診：五種指紋，三種可治、兩種禁忌

白話版：吃藥會好的，跟必須開刀的

補償的本質是「拿 L 抵 C、拿 C 抵 L」——所以它只治得了「集總的 L/C 失衡」這一種病。TDR 上五種指紋裡：凹陷（C 多）、尖峰（L 多）、扭波（C-L-C 沒配平）是這種病，可治。但台階（一整段線的阻抗就是錯的）是「體質問題」——錯的是分布參數，你在一個點上加減 L/C 救不了一整段線；週期性深凹（stub 諧振）是「結構問題」——諧振是能量在一根分岔裡來回震盪，你配平它的入口電容也擋不住 f₀ 的能量被吸走；墊高（電阻性）更不用說——R 跟 L/C 是不同物種，蹺蹺板上根本沒有它的位置。對這三種「不可補償」的病，藥方分別是：改幾何/疊構、移除 stub、FA 修接觸。分診分錯，後面全錯。

常見誤區：「TDR 有凹就掏參考層」

掏空是好藥，但先分診。三個真實的誤用場景：①凹陷其實是台階的開頭（後面沒有回到基準線）——那是一段線寬畫錯的線，掏 pad 下方那一小塊救不了整段，反而在錯的位置多加一個尖峰；②凹陷是stub 的入口電容——掏空能把入口的凹修淺，但 f₀ 的諧振吸收一點都不會少，眼圖照樣塌（Day 11：諧振是能量問題不是阻抗問題）；③凹陷後面墊高——那是接觸電阻，掏了地還是墊高。藥方永遠跟著病理走，不是跟著波形長相走。

白話版：藥櫃的抽屜只分四格

看起來八味藥很多，其實抽屜只有四格：減 C（anti-pad、除 pad、瘦身、掏空）、減 L（回流 via、低背、就近地）、加 L / 加 C（頸縮細線、pad 略放大——用得少但存在）、移除結構（back-drill、剪針、不開分支——這格治的是「禁忌症」，嚴格說不是補償，是開刀）。拿到病例先問：我要推哪個方向？再從那格抽屜裡挑一味在你的板子上「動得了」的藥——很多時候不是最有效的藥先用，而是談判成本最低的藥先用（改 anti-pad 不用跟任何人吵；瘦 pad 要跟製程吵；換 connector 要跟機構吵）。

4. Via 的出線與《Perfect Timing II》的三招——2002 年藥方的現代校訂

《Perfect Timing II》Ch.6 對 via 的第一句話其實是「別用」：「佈clock 走線時，訊號應該留在同一個訊號層。用 via 轉到其他層會劣化 clock 的訊號品質——因此應避免使用 via。」（Perfect Timing II Ch.6）這就是藥方櫃之外的第零藥方：最好的補償，是讓不連續根本不存在。能不換層就不換層、能不開測試分支就不開（Day 11 談判）、能用 SMT 就不用 through-hole——每一個省下來的不連續，都是省下來的補償工程與量測驗證。

當 via 躲不掉時，PT2 Ch.6 給了三招（原文照列）：

  1. 「把 via 做得越大越好（面積越大，電感與電阻越小）」（Perfect Timing II Ch.6）
  2. 「外層以最大銅厚電鍍」（Perfect Timing II Ch.6）
  3. 「將 via 孔電鍍加厚或填實（filling solid）」（Perfect Timing II Ch.6）
2002 年的藥方，2026 年要校訂——「加大 via」不再一體適用

PT2 成書時的主戰場是百 MHz 量級的 clock：那個年代 via 的病主要是 R 與 L（granular copper 的電阻、細桶身的電感），所以「加大、鍍厚、填實」三招全部往 R↓ L↓ 推，完全正確。但現代多 Gbps serial（MIPI、USB4、PCIe）的 via，病常常反過來是 C 與 stub：大 via 意味著大 pad、大桶身對參考層的電容——「加大 via」在今天的高速訊號 via 上可能把凹陷挖得更深。以現代標準需修訂為：訊號 via 傾向小孔徑＋優化 anti-pad＋back-drill；「加大、鍍厚、填實」三招保留給電源 via（那裡 R 與 L 仍是主要敵人，PT2 的邏輯原封不動成立）。這是「引用經典要帶年份」的標準示範——面試時能講出「這個建議的適用前提」比背出建議本身值錢得多。

還有一段 PT2 原文正好是 anti-pad 加大的「另一面」，兩相對照非常精彩：「在穿過參考平面的孔周圍留過大的間隙（clearance）也許讓製造容易，但可能迫使回流電流走非最佳路徑——間隙孔的效應應該被分析。」（Perfect Timing II Ch.6）換句話說：anti-pad 是「減 C 的藥」，也是「在回流平面上開的洞」——同一個幾何、兩個效應，加大到某個程度後回流繞行的 L↑ 會反超 C↓ 的好處。這跟 Day 12 掏空補償「外科手術 vs 捅刀子」是同一堂課：劑量，永遠是劑量。

5. 補償的極限：配平只保證反射小，不保證頻寬夠

白話版：減速丘鋪得再平順，還是減速丘

把 C-L-C 配平到 50 Ω，好比把馬路上的減速丘鋪上漂亮的緩坡——低速開過去完全無感（低頻訊號看不到它）。但坡就是坡：車速夠快（頻率夠高）時，再平順的坡也會讓車子飛起來。配平消滅的是「反射」，消滅不了「這裡有一坨 L 和 C」的事實——一段集總的 LC 結構天生是個低通濾波器，頻率高過它的截止頻率，訊號就是過不去。所以補償有一條硬天花板：結構的 LC 越大，天花板越低——這就是為什麼「小而平衡」永遠贏「大而平衡」，也是為什麼到了某個速率，你只能換掉整顆 connector 而不是繼續調 pad。

配平後的不連續段等效於一節 LC 低通（把它看成人工傳輸線的一節），其截止頻率量級：

f_c ≈ 1 / (π√(LC))

白話翻譯：L 和 C 相乘開根號＝這個結構的「時間體積」；體積越大，能通過的頻率越低。配平（L/C 的「比例」）管反射，√(LC)（L 與 C 的「總量」）管頻寬——比例和總量是兩個獨立的自由度，補償只調了前者。

代兩組 Day 12 的數字感受一下（都是完美配平的 50 Ω 結構）：

  • 低背 BTB：L = 1.0 nH、C = 0.4 pF → √(LC) = 20 ps → f_c ≈ 16 GHz 量級——對 MIPI 4.5 Gbps（能量主要在 10 GHz 內）綽綽有餘。
  • 高背 connector 硬補到配平：L = 2.5 nH、C = 1.0 pF → √(LC) = 50 ps → f_c ≈ 6 GHz 量級——TDR 上看起來「平了」，可是跑 10 Gbps 級的訊號眼圖照樣塌。TDR 拉平 ≠ 通道合格，這是本課最重要的一句警語。

這也解釋了公理三的另一面：配平的 C-L-C 要「扮演一小段 50 Ω 線」，前提是訊號的頻率成分對它而言都是「低頻」——f_c 就是這場扮演穿幫的頻率。於是「何時該認輸改架構」有了定量判準：

認輸判準：補償 vs 改架構

①算出結構配平後的 f_c，跟訊號的頻寬需求（NRZ 常抓到 0.75×資料率以上、加上餘裕，量級估算）比——f_c 沒有明顯高於需求，補償這條路直接放棄，換低背、換 SMT、換更短的結構，把 √(LC) 本身砍小；②禁忌症三種（台階／諧振／電阻）從一開始就不進補償流程；③補償迭代兩輪（改版→TDR）還收不斂，通常代表模型漏了什麼（常見：回流路徑沒進模型）——停下來重看，不要進入第三輪玄學調參。改架構聽起來成本高，但比起連改三版 PCB，換一顆料常常是便宜的那條路。

6. 把它變成流程：手算 → 模擬 → TDR 回診

方法論最後一塊：藥方不是一次開到位，是一個閉環。

  1. 分診（本課第 2 節）：TDR 指紋 → 可補償 or 禁忌症。禁忌症走各自的路（改幾何／back-drill／FA）。
  2. 手算定方向與量級（公理一、二）：面積 → 欠多少 pF 或 nH → 該往哪格抽屜拿藥、劑量是大是小。手算的精度大約只有 ±幾十 %，但它決定「方向對不對」——方向錯了，模擬跑得再準都是精確地走錯路。
  3. 模擬精算：3D 場解算器（HFSS 類）算 connector/via 結構、2D 場解算器算走線——第 6 週講量測時再展開工具鏈。模擬的角色是把手算的「量級」收斂成「尺寸」：anti-pad 直徑、void 長寬。
  4. TDR 回診（公理一再用一次）：打樣回來量，殘餘的凹/尖面積就是「還欠多少」的處方箋。收斂判準事先定好（例如通道 spec 換算的 ρ 上限），不要「看起來蠻平的」。
  5. 兩輪不收斂 → 回第 1 步重新分診（最常見的漏診：回流路徑、以及把禁忌症誤當適應症）。

7. 實務案例：三個現場

  • NB 主機板——換層 via 的標準配置：主板上 USB/DP 高速線從 L1 換到內層，SI 檢查清單就是圖 2 那顆 via：anti-pad 有沒有優化、非功能 pad 有沒有刪、要不要 back-drill（板厚與速率決定）、回流 via 有沒有貼著放。這四項在 layout review 時是逐條打勾的例行公事——今天之後你看得懂每一條「為什麼」。
  • 鏡頭模組——「補償收不斂」的真實劇本：模組 MIPI 通道 TDR 在 BTB 處有凹陷，第一版改 footprint 掏空——凹陷變淺但沒消失；第二版加大掏空——凹陷處反而長出小尖峰（過補償），而且眼圖還是不合格。分診重來才發現：真正的病是ground pin 分配不足（回流繞路的 L 與 lane 間耦合）——病灶在 pin map，不在 pad 電容。藥方是換 pin assignment（原理圖層級），不是繼續雕地板。這正是第 6 節「兩輪不收斂→重新分診」的教科書案例，也是 Day 12「pin map 定生死」的續集。
  • 面試白板：「Here's a TDR with a dip. Fix it.」——標準的分層答法：先問（或假設）dip 是一過性還是台階開頭 → 面積反推 C_excess → 列兩格抽屜（減 C／加 L）各兩味藥＋各自的談判成本 → 主動講出 f_c 天花板與「TDR 平了不等於眼圖開」。這一套講完，面試官知道你不是背 checklist，是真的有方法論。

8. 動手練習（紙筆題，不需儀器）

先自己算完再展開詳解。週五實作日會拿真波形對答案。

練習 1（完整開藥流程）：50 Ω 通道 TDR 在測試點位置有一個一過性凹陷，面積 A ≈ 7.5 ps（ρ·時間），凹陷後回到基準線。(a) 反推 C_excess。(b) 若選「加 L」路線配平，需要多少 nH？(c) 列出「減 C」抽屜裡可用的三味藥。(d) 你會先試哪一味？用「談判成本」說明。

解：(a) 公理一：C_excess = (2/Z₀)×A = (2/50)×7.5 ps = 0.3 pF。(b) 公理二：L = 2.5×0.3 = 0.75 nH。(c) 減 C 三味：pad 正下方參考層掏空、pad 瘦身（跟探針/製程需求談）、若凹陷其實含 via 成分則加大 anti-pad＋刪非功能 pad。(d) 先試掏空：只動參考層一小塊銅，不影響焊接與探測、不用跟製程或測試部門談判，改版風險最低；瘦 pad 要過製程關、動 anti-pad 牽動的是 via 而非 pad 本身。（順帶檢查公理三：測試點 pad 尺寸 mm 級，遠小於一般 t_r 的空間長度，補償資格成立。）

練習 2（頻寬天花板）：兩顆候選 connector 都能藉 footprint 調整做到配平。甲：L=0.8 nH、C=0.32 pF；乙：L=3.0 nH、C=1.2 pF。(a) 驗證兩顆都配平在 50 Ω。(b) 各算 f_c 量級。(c) 通道要跑 10 Gbps NRZ（頻寬需求抓到約 7.5 GHz 以上、留餘裕），哪顆能用？(d) 用一句話說明為什麼「TDR 都平」但結論不同。

解：(a) 甲：√(0.8n/0.32p)=√2500=50 Ω ✓；乙：√(3.0n/1.2p)=√2500=50 Ω ✓。(b) 甲：√(LC)=√(0.8n×0.32p)=16 ps → f_c ≈ 1/(π×16 ps) ≈ 20 GHz 量級；乙：√(LC)=60 ps → f_c ≈ 5.3 GHz 量級。(c) 需求約 7.5 GHz＋餘裕：甲可用；乙的 f_c 直接落在頻帶內，不合格——而且無藥可補，因為它已經配平了，剩下的病是 √(LC) 總量太大，只能換料。(d) 配平（比例）管反射、√(LC)（總量）管頻寬——TDR 的平坦只證明了前者。

練習 3（anti-pad 的兩難）：為了修 via 的容性凹陷，同事提議「anti-pad 直接開到三倍大，一次到位」。(a) anti-pad 加大為什麼能減 C？(b) 引用 PT2 Ch.6 的哪句原文可以提醒他風險？物理機制是什麼？(c) 給出一個工程上的收斂做法。(d) 這個兩難跟 Day 12 的哪個主題是同一堂課？

解：(a) via barrel／pad 與參考層邊緣之間的距離拉大 → 電力線更難閉合到平面 → 對地電容下降。(b) PT2 Ch.6：「在穿過參考平面的孔周圍留過大的間隙也許讓製造容易，但可能迫使回流電流走非最佳路徑——間隙孔的效應應該被分析。」機制：anti-pad 就是參考平面上的洞，鄰近走線的回流（以及 via 自己的回流交接）被迫繞洞緣 → L↑、串擾↑；加大到某個程度，L↑ 的害處反超 C↓ 的好處，凹陷還會翻成尖峰（過補償）。(c) 從廠商建議或模擬起步、每輪小步調整、TDR 面積收斂到目標即停——「效應應該被分析」這半句就是答案本身。(d) Day 12 掏空補償 vs「cutout 必須避免」的一線之隔——同一把刀，差別在有沒有算過、有沒有量。

練習 4（分診急診室）：四張 TDR 病例，各自判「可補償／禁忌症」並開藥：(A) 凹陷後曲線停在比基準低 8% 的新水平不回來；(B) 一過性尖峰，面積 5 ps；(C) 走線中段一個凹，用更快的 TDR 邊沿重量後凹「變深且變出周期性」，通道眼圖在特定頻率附近塌陷；(D) connector 處扭波，扭完回基準，但面積比 known-good 板大 50%。

解：(A) 禁忌症——台階（持續的新水平＝後段整段線阻抗偏低）：查線寬/疊構/該段參考層距離，改幾何，點補償無效。(B) 可補償：L_excess = 2Z₀×A = 100×5 ps = 0.5 nH；藥：回流 via 貼近／低背化砍 L，或補 C 0.2 pF（0.5/2.5）配平——順序上先查回流（免費）再動結構。(C) 禁忌症——stub 諧振：快邊沿下現出周期性＋特定頻率塌＝諧振腔特徵（Day 11）；藥是 back-drill／移除分支，不是配平入口電容。(D) 可補償（且健康地回基準＝無電阻性問題）：面積多 50% ＝ L/C 失衡量多 50%——對照 known-good 查 footprint 差異（掏空漏做？anti-pad 版本錯？），把配平調回來。四例合一句：先問「一過性？持續？周期性？」再開藥。

練習 5（PT2 三招的現代校訂）：PT2 Ch.6 對 via 的三招是「加大、外層鍍厚、填實」。(a) 2002 年這三招針對的是 via 的哪兩個寄生參數？當年的主戰場是什麼訊號？(b) 為什麼「加大」用在 2026 年的 10 Gbps 訊號 via 上可能適得其反？(c) 這三招今天完整保留給哪一類 via？為什麼那裡的邏輯不變？(d) 訊號 via 的現代對應清單是什麼？

解：(a) 針對 R 與 L（granular copper 電阻、桶身電感）；主戰場是百 MHz 量級的 clock 佈線——邊沿慢、頻寬窄，via 的 C 幾乎無感。(b) 加大 via ＝ 加大 pad 與桶身對參考層的面積 → C↑；現代高速 serial 的 via 病灶常是容性凹陷＋stub 諧振，加大反而把凹陷挖深。(c) 電源 via：電源路徑的敵人到今天仍是 R（IR drop）與 L（PDN 阻抗）——加大、鍍厚、填實、多打並聯，PT2 邏輯原封不動（第 7-8 週 PDN 再展開）。(d) 訊號 via：小孔徑、優化 anti-pad、移除非功能 pad、back-drill、緊鄰回流 via——外加第零藥方：能不換層就不換層（PT2：「訊號應留在同一層」）。

9. 面試怎麼考

補償方法論是 Apple/Google camera HW 面試的高頻主戰場——它同時暴露你的物理直覺、量化能力與工程判斷。先英文口述，再看參考答案。

Q1: "Our 10 Gbps channel shows a capacitive dip at a via transition on the TDR. A junior engineer suggests enlarging the anti-pad until the dip disappears. How would you approach this?"

參考答案骨架：Enlarging the anti-pad is the right direction but the wrong methodology if we just keep enlarging until the dip "disappears." First I'd quantify the problem: the area of the dip on the TDR gives me the excess capacitance directly — height depends on the instrument rise time, but area doesn't. Say it's 0.3 pF; in a 50-ohm system that needs either 0.3 pF removed or about 0.75 nH added to rebalance, since matching means L equals Z-nought squared times C. Then I'd use the full toolkit, not just the anti-pad: remove non-functional pads on unused inner layers, check whether the via needs back-drilling — because if part of that dip is actually a stub resonance, no amount of anti-pad tuning will fix the eye — and make sure there's a ground return via right next to the signal via. On the anti-pad specifically, there's a real limit: it's a hole in the reference plane, so oversizing it forces return currents to detour, which adds inductance and crosstalk — you can overshoot and turn the dip into a peak. So: calculate, adjust in small steps, verify by TDR area, and stop at the target. And one more check before any of this — the cutoff frequency of the compensated structure, roughly one over pi root LC. If the via's total LC is too big, a flat TDR still won't give me an open eye at 10 gig, and the real fix is a shorter via — thinner board section or different layer assignment — not a bigger hole in my ground plane.

加分點：「area not height」「rebalance not eliminate」「a flat TDR is not a passing channel」三句金句；主動提到 anti-pad 的回流代價（PT2 Ch.6 的 clearance 警告即此），顯示你知道每味藥的副作用。

Q2: "What are the fundamental limits of impedance compensation? When do you stop tuning pads and voids, and change the design instead?"

參考答案骨架：Compensation has three hard limits. First, it only treats one disease: a lumped L-C imbalance. A step change in the TDR means a whole segment has the wrong characteristic impedance — that's a distributed problem, and no point-compensation fixes a distributed error; you fix the trace geometry or the stackup. A resonating stub stores energy at its quarter-wave frequency — balancing its entrance capacitance doesn't stop the resonance; you remove the stub. And a persistent level shift is resistive — that's a failure-analysis problem, not a design-tuning problem. Second, even for the right disease, there's a bandwidth ceiling: a balanced C-L-C section is still a low-pass filter with a cutoff around one over pi root LC. Balancing the L-to-C ratio kills the reflection, but the product LC sets the bandwidth — those are two independent knobs and compensation only turns the first one. So a physically large connector can be perfectly balanced, show a flat TDR, and still close the eye at high data rates. When the required bandwidth approaches that cutoff, I stop tuning and shrink the structure itself — lower stack height, surface-mount instead of through-hole, fewer layer transitions. Third, a practical limit: if two board revisions with simulation-guided tuning haven't converged, my model is missing something — in my experience it's usually the return path, like insufficient ground pins on a connector — and the fix belongs at the schematic or component-selection level, not in the copper tweaks. Knowing when compensation is the wrong tool is, I think, the actual senior skill being tested here.

加分點：「ratio vs product — two independent knobs」是這題的靈魂句；第三點把「模型漏回流」講成親身經驗（可接 Day 12 的 pin map 案例當 STAR 故事），會讓面試官追問——那正是你想要的。

10. 今日 Anki 卡片

Q1：補償設計三公理？

A1：①面積反推：L_excess=2Z₀×A（尖峰）、C_excess=(2/Z₀)×A（凹陷）——高度看儀器、面積看真相；②配平：Z_local≈√(L/C)、L=Z₀²C（50 Ω：L[nH]=2.5×C[pF]）——調比例不是消滅；③集總條件：結構長度 ≪ t_r 空間長度（約 1/6 門檻）——夠短，C-L-C 才能合演一段 50 Ω 線。流程：面積算欠多少→配平算補多少→檢查有沒有補償資格。

Q2：TDR 五指紋的分診——哪些可補償、哪些是禁忌症？

A2：可補償（集總 L/C 失衡）：一過性凹陷（C 多）、一過性尖峰（L 多）、扭波（C-L-C 沒配平）。禁忌症：台階（一整段 Z₀ 錯＝分布性問題→改線寬/疊構）、stub 週期性諧振（能量儲存→back-drill/移除，配平入口 C 無效）、墊高不回基準（電阻性→FA：重插/切片/鍍層）。口訣：一過性的交給蹺蹺板；持續的、週期的、電阻的動結構。

Q3：補償的頻寬極限公式？「小而平衡 vs 大而平衡」？

A3：配平後的 C-L-C 仍是低通，f_c ≈ 1/(π√(LC))。比例（L/C）管反射、總量（LC）管頻寬——兩個獨立旋鈕，補償只轉前者。例：L=1 nH/C=0.4 pF → f_c≈16 GHz 量級；L=2.5 nH/C=1 pF（同樣配平）→ 約 6 GHz 量級。TDR 拉平 ≠ 眼圖會開；f_c 沒明顯高於訊號頻寬需求→放棄補償、把結構做小（換低背/SMT/少換層）。

Q4：一顆換層 via 的標準補償配置四件套？各推哪個方向？

A4：①anti-pad 加大→C↓（但過大＝參考平面破洞，PT2 Ch.6：clearance 過大迫使回流繞行，效應應被分析）；②非功能 pad 移除→C↓；③back-drill→移除 stub 諧振（治禁忌症，殘樁約 0.2 mm 量級）；④緊鄰回流 via→回流迴圈 L↓（訊號換層、回流也要換層）。外加第零藥方（PT2 Ch.6）：「訊號應留在同一層，via 應避免」——最好的補償是不需要補償。

Q5：PT2 Ch.6 via 三招原文？現代校訂怎麼講？

A5：三招：加大 via（面積大→L、R 小）、外層最大銅厚電鍍、孔內鍍厚或填實。背景：2002 年百 MHz clock，via 的病是 R 與 L。現代校訂：多 Gbps serial 訊號 via 的病常是 C 與 stub——「加大」反而增 C 挖深凹陷；訊號 via 改用小孔徑＋anti-pad 優化＋back-drill；三招原封保留給電源 via（R/IR drop 與 L/PDN 阻抗仍是主敵）。引用經典要帶年份與適用前提。
