0. 為什麼這一課這麼重要？

打開任何一張 NB 主機板的原理圖，數一下 MOSFET 的數量——電源樹上的 load switch、DC-DC buck 的上下橋、電池切換的 back-to-back 對管、USB 埠的過流保護、鏡頭模組電源的 gating……一張板子上輕鬆超過 50 顆。MOSFET 是硬體工程師最常畫、卻最容易「會用但講不出原理」的元件。

Apple／Google 的 HW EE 面試非常愛考 MOSFET，因為它一題可以同時測出你三層功力：

  • 元件物理層：Vth 是什麼？為什麼有三個工作區？
  • 電路設計層：高邊開關為什麼有時用 P-MOS、有時用 N-MOS？bootstrap 怎麼運作？
  • 實務除錯層：為什麼這顆 MOSFET 燒了？Miller plateau 是什麼、跟誤導通有什麼關係？

這一課會把三層一次補齊。公式看不懂的地方可以先跳過，每一段的白話結論才是主幹，數學只是把結論釘牢的釘子。

1. MOS 結構直覺：一顆用電壓控制的水龍頭

白話版

MOSFET 就是一顆用電壓控制的水龍頭：

  • Source（源極）＝進水口，Drain（汲極）＝出水口
  • Gate（閘極）＝水龍頭的把手。你轉把手不需要出力搬水，只要「轉到位」，水就自己流
  • 通道（channel）＝水管內的閥門開口。把手轉越多，開口越大，水流越大
  • Vth（臨界電壓）＝把手的「空轉段」。把手剛開始轉的前幾度是空的，要轉超過某個角度水才開始流

最關鍵的一句話：gate 是「用電場隔空控制」的，它跟水路（source–drain）之間隔著一層絕緣的氧化層，穩態時幾乎不消耗任何電流。這就是 MOSFET 和 BJT（用電流控制）最大的差別，也是它統治數位電路和電源開關的原因。

1.1 剖面結構：M-O-S 三個字母各是什麼

MOSFET 全名 Metal-Oxide-Semiconductor Field-Effect Transistor（金屬–氧化物–半導體場效電晶體），名字就是它的三明治結構由上而下唸一遍：

  • M（Metal，金屬閘極）：最上層的導體電極（現代製程多為多晶矽或金屬閘），就是「把手」。
  • O（Oxide，閘極氧化層）：一層極薄的絕緣體（SiO₂ 等），把把手和水路隔開。它讓 gate 只能用電場、不能用電流去影響下面的半導體。
  • S（Semiconductor，半導體基板）：矽基板，水路的本體。以 NMOS 為例：p 型基板上做兩個 n+ 重摻雜區，分別是 source 和 drain。

平常（gate 沒加電壓時），source 和 drain 這兩個 n+ 區之間隔著 p 型基板——等效於兩顆背對背的二極體，不管電流想從哪個方向走都會被其中一顆擋住，所以水路是斷的。

當你在 gate 加正電壓（相對於 source），gate 下方的電場會把 p 型基板裡的電子「吸」到氧化層正下方的表面，聚集到一定濃度後，表面那薄薄一層的性質反轉成 n 型——這叫反轉層（inversion layer），它把 source 和 drain 兩個 n+ 區連了起來，形成一條 n 型通道，水路接通。

關鍵結論

MOSFET 是電壓控制元件：gate 隔著絕緣氧化層，用電場控制通道的導電程度。穩態時 gate 電流幾乎為零；但切換瞬間需要對 gate 的寄生電容充放電，這時 gate 是要吃電流的——這句話是後面 Qg、Miller 效應、gate driver 三個主題的種子，先記住。

2. 四種基本口味：NMOS／PMOS × 增強型／空乏型

白話版

MOSFET 有兩個獨立的分類軸，組合成四種：

  • NMOS vs PMOS＝水往哪個方向壓才順。NMOS 是「gate 加正電壓開」，PMOS 是「gate 加負電壓（比 source 低）開」。
  • 增強型 vs 空乏型＝水龍頭出廠時是關的還是開的。增強型（enhancement）出廠常關，要加電壓才開；空乏型（depletion）出廠常開，要加反向電壓才關。

實務上你在板子上畫的 99% 都是增強型：增強型 NMOS 和增強型 PMOS。空乏型幾乎只出現在特殊場合（如恆流源、常開保護電路），知道它存在、面試被問到不慌就好。

2.1 NMOS vs PMOS 對照

增強型 NMOS增強型 PMOS
基板／通道p 基板、n 通道（載子＝電子）n 基板、p 通道（載子＝電洞）
導通條件Vgs > Vth（Vth 為正）Vgs < Vth（Vth 為負，即 gate 比 source 低超過 |Vth|）

同尺寸下的表現電子遷移率高 → Rds(on) 較低（同面積約低 2～3 倍，量級）電洞跑得慢 → 同規格要更大的 die、更貴

常見誤區

「Vgs」永遠是 gate 相對 source 量的，不是相對 GND！這是新手看高邊電路最容易犯的錯。一顆 PMOS 的 source 接在 5V 電源上，gate 接 GND 時 Vgs = 0 − 5 = −5V → 導通；gate 接 5V 時 Vgs = 0 → 關閉。看任何 MOSFET 電路的第一步，永遠是先找到 source 在哪，再算 Vgs。（分辨方向的小技巧：對增強型元件，電路符號上 body diode 的方向可以幫你定位 source——NMOS 的 body diode 陽極在 source；電流「正常」流向是 NMOS 由 D 到 S、PMOS 由 S 到 D。）

3. Vth 與三大工作區：看懂 I-V 曲線

3.1 Vth：把手的空轉段

白話版

gate 電壓要「吸」出足夠多的電子才能形成通道，在那之前吸出來的電子都被基板裡的正電荷「吃掉」了——就像把手前幾度的空轉。這個門檻就是臨界電壓 Vth。

實務上要知道：小訊號／邏輯電平 MOSFET 的 Vth 約 0.4～2V（量級），功率 MOSFET 常見約 1～4V。datasheet 上的 Vgs(th) 是在極小電流（如 250 µA）下定義的「剛剛開始滲水」的點，不是「可以全開扛大電流」的電壓——這是選料時最經典的坑，後面 4.1 再展開。

3.2 三大工作區

以 NMOS 為例（PMOS 全部符號反過來即可），依 Vgs 和 Vds 的相對大小，分三區：

工作區條件白話比喻元件像什麼用在哪
截止區（cutoff）Vgs < Vth把手還在空轉段，閥門全關開路（斷開的開關）開關的 OFF 態
線性區／三極體區（triode / linear）Vgs > Vth 且 Vds < Vgs − Vth閥門大開、上下游水位差很小，水流大小由水位差決定一顆可調電阻（Vds 很小時 Id ∝ Vds）開關的 ON 態（Rds(on) 就住在這區）
飽和區（saturation）Vgs > Vth 且 Vds ≥ Vgs − Vth閥門開口固定、下游怎麼抽水流都不變——水流只由把手角度決定一顆由 Vgs 控制的電流源放大器、恆流源；開關切換的過渡瞬間會路過這區（損耗發生地）
常見誤區

MOSFET 的「飽和區」跟 BJT 的「飽和區」意思完全相反！BJT 飽和＝開關全開（深度導通）；MOSFET 飽和＝電流源區（放大區）。開關全開時 MOSFET 待在線性區。面試講英文時建議用 “triode/ohmic region” 和 “saturation (active) region” 明確區分，展現你知道這個命名地雷。

看曲線的三個口訣
  1. 左邊陡坡＝電阻：斜率的倒數就是 Rds，Vgs 越大坡越陡、電阻越小。
  2. 右邊平台＝電流源：Vds 再怎麼加，Id 幾乎不動（實際有微微上翹，那是通道長度調變，等效輸出電阻 ro）。
  3. 開關的一生：OFF（截止，貼著橫軸）→ 切換瞬間爬過飽和區（同時有大 Vds 和大 Id，最耗損的一段路）→ ON（線性區深處，貼著縱軸旁）。

4. 當開關用：選料四大天王

4.1 Rds(on)：全開後的水管阻力

白話版

開關全開後，MOSFET 就是一顆小電阻。電流流過它會發熱：P = I² × Rds(on)，這叫導通損耗（conduction loss）。電流越大的軌，越需要低 Rds(on) 的料。

讀 datasheet 時的三個重點：

  • Rds(on) 一定要看測試條件的 Vgs。同一顆料，Vgs = 10V 時可能約 5 mΩ，Vgs = 4.5V 時約 8 mΩ，Vgs = 2.5V 時也許根本沒 spec（不保證能用）。你的 gate 驅動電壓有多少，就查那一欄。
  • Vgs(th) ≠ 可以全開的電壓。Vth 是「開始滲水」（約 250 µA 那種等級），要讓 Rds(on) 到 spec 值，Vgs 通常要比 Vth 高出好幾伏。用 1.8V GPIO 直推一顆 Vth = 1.5V 的功率管，它「有導通」但是在半開狀態，Rds 可能是 spec 的十倍以上，輕則壓降超標、重則燒管。
  • Rds(on) 有正溫度係數：溫度升高，Rds(on) 跟著升（125°C 時常見約為 25°C 值的 1.4～1.8 倍，量級）。好處是多顆並聯會自動均流（熱的那顆電阻變大、分到的電流變少），這是 MOSFET 比 BJT 容易並聯的原因，面試加分點。

4.2 Gate charge Qg：把手有多重

白話版

雖然穩態不耗電，但每一次開關，driver 都要把一包電荷 Qg 搬進 gate（開）再搬出來（關）——就像把手雖然不用一直握著，但每轉一次都要出一次力。Qg 越大，把手越重：切換越慢、driver 越吃力、開關頻率越高時驅動損耗越大。

驅動損耗 Pgate = Qg × Vgs × fsw

白話翻譯：每秒開關 fsw 次，每次搬 Qg 的電荷、每包電荷付 Vgs 的「運費」。這個損耗發生在 driver 和 gate 電阻上，不在 MOSFET 通道裡。公式看不懂沒關係，記住結論：高頻開關（如 buck 的 1 MHz 級）要挑小 Qg；慢速 load switch（幾乎不切換）Qg 無所謂。

4.3 開關損耗 vs 導通損耗：魚與熊掌

白話版

MOSFET 發熱有兩個來源：

  • 導通損耗＝全開之後電流持續流過 Rds(on) 的熱——「水管太細的摩擦熱」。跟開關頻率無關，跟電流平方成正比。
  • 開關損耗＝每次切換的過渡瞬間，Vds 和 Id 同時不為零那幾十奈秒產生的熱——「閥門開一半時水流又急、壓差又大，最磨損」。每切一次付一次，跟頻率成正比。

殘酷的取捨：低 Rds(on)（die 大）↔ 大 Qg（切得慢、開關損耗大），同一世代製程下兩者的乘積 Rds(on)×Qg 大致是個常數（稱為 FOM，品質因數）。所以：慢開關（load switch）挑 Rds(on) 低的；快開關（DC-DC）在兩者間找平衡。

Pcond = Irms² × Rds(on) × D　；　Psw ≈ ½ × Vds × Id × (ton + toff) × fsw

白話翻譯：左式＝電流平方乘電阻（再乘導通時間比例 D）；右式＝每次切換的「三角形能量」（電壓電流交疊的面積）乘每秒切換次數。不想推導沒關係，只要會判斷：「這顆料燒，是因為電流太大（換低 Rds(on)）？還是因為切太頻繁／切太慢（換低 Qg、加強 driver）？」

4.4 Body diode：買一送一的寄生二極體

回看圖 1：分離式（discrete）MOSFET 的基板（body）在封裝內部接到 source，於是 body–drain 之間的 pn 接面就成了一顆永遠存在、不受 gate 控制的二極體——NMOS 的 body diode 方向是 S→D（陽極在 S）。

  • 好處：buck 的 dead time 期間，電感電流靠低邊管的 body diode 續流，不會斷路打火。
  • 壞處 1：它讓單顆 MOSFET 只能擋一個方向的電壓。反方向電流會直接從 body diode 溜過去——這就是為什麼電池／adapter 電源切換要用兩顆 back-to-back（共 source 或共 drain 對接），讓兩顆 body diode 背對背互相擋住。
  • 壞處 2：body diode 壓降大（約 0.7～1V）、反向恢復（reverse recovery）慢，高頻電路裡它導通過的每一段時間都是損耗與雜訊來源。

5. 寄生電容與 Miller 效應：為什麼 gate 波形會卡出一個平台

白話版

MOSFET 的三隻腳兩兩之間都「隔著很近的導體」，天生就是三顆小電容：Cgs（gate–source）、Cgd（gate–drain）、Cds（drain–source）。其中最麻煩的是 Cgd，它像一條「從出水口偷偷接回把手的回饋水管」：

你想開閥門（拉高 gate）→ 閥門一開，出水口的壓力（Vd）就往下掉 → 這個下掉的壓力透過 Cgd 「拽住」把手不讓它繼續轉 → driver 灌進來的電流全被拿去填 Cgd 這個無底洞 → gate 電壓就卡在原地不動，形成一段平台（Miller plateau），直到 drain 電壓掉完為止，gate 才繼續往上爬。

一句話：Miller plateau ＝ gate 電壓暫停爬升的那段時間，因為 driver 的電流正在全力對付「被 drain 電壓擺幅放大了的 Cgd」。plateau 越長，切換越慢，開關損耗越大——因為整段 plateau 期間元件正好處在「電壓電流都大」的飽和區。

5.1 datasheet 上的三個電容名字

datasheet 名稱組成意義
Ciss（輸入電容）Cgs + Cgddriver 看進去的電容，決定驅動難度
Coss（輸出電容）Cds + Cgd每次開關要充放的輸出端電容，貢獻開關損耗（½CossV²f）
Crss（反向傳輸電容）CgdMiller 電容本尊，越小越好切

5.2 Miller 效應的數學（看不懂可跳過）

等效輸入電容 Cin ≈ Cgs + Cgd × (1 + |Av|)，其中 Av = ΔVd/ΔVg（drain 對 gate 的電壓增益）

白話翻譯：因為 gate 每動 1V、drain 反向動 |Av| V，跨在 Cgd 上的電壓變化是 (1+|Av|) V——所以從 gate 看，這顆小電容「膨脹」成 (1+|Av|) 倍。開關切換瞬間 drain 要擺完整個電源電壓（例如 12V），而 gate 只動零點幾伏，等效放大倍率極大，於是 Cgd 瞬間吃光所有驅動電流 → plateau。plateau 的電壓高度就是「維持當前負載電流所需的 Vgs」（Vplateau ≈ Vth + Iload/gm），plateau 的時間長度 ≈ Qgd ÷ driver 電流。

實戰陷阱：dV/dt 誤導通

Cgd 還有一個反向搞破壞的方式：當 drain 電壓被別人快速拉高（例如 buck 上管開通時，下管的 drain 瞬間從 0V 跳到 12V），這個 dV/dt 會透過 Cgd 對「應該關著」的下管 gate 注入電流，若 gate 迴路阻抗太高，gate 電壓可能被抬過 Vth → 上下管瞬間同時導通（shoot-through）。對策：gate 驅動迴路要低阻抗、gate 電阻不要亂加大、選 Cgd/Cgs 比例好的料。你如果量過 buck 下管 gate 上那些幾百 mV 的毛刺，就是這個機制。

6. Gate driver：為什麼不能用 GPIO 直推

白話版

把手很重（Qg 幾十 nC），而 GPIO 是一隻小手（源出／灌入能力約幾 mA）。小手轉重把手＝轉得超慢＝閥門長時間停在「半開最磨損」的位置。gate driver 就是一隻專門轉把手的大力士手臂：能瞬間提供安培級的電流，把 plateau 壓縮到幾十奈秒內結束。

gate driver 提供的四件事：

  1. 大電流：常見約 0.5～4A 峰值源出／灌入，t ≈ Qg/Idrv，電流大十倍、切換快十倍。
  2. 電平轉換：把 1.8V/3.3V 邏輯訊號轉成功率管需要的 5V/10V/12V 驅動電壓。
  3. 高邊驅動能力：內建 bootstrap 或電荷泵，解決「N-MOS 放高邊時 gate 要比電源還高」的難題（下一節）。
  4. 保護功能：dead-time 產生、欠壓鎖定（UVLO）、有些含 Miller clamp（主動把關著的 gate 掐在低電位，防 dV/dt 誤導通）。

那什麼時候可以不用 driver？慢速 load switch：切換一次花幾百 µs 也無所謂（甚至刻意加 RC 放慢做 soft-start、壓 inrush），GPIO＋一顆小 NPN/PMOS 拉 gate 就夠——這正是 NB 板上大多數電源 gating 的做法。

7. 高邊開關：P-MOS 派 vs N-MOS＋bootstrap 派

白話版

「高邊開關」＝開關串在電源與負載之間（斷電源）；「低邊」＝串在負載與 GND 之間（斷地）。實務幾乎都要斷電源（斷地會讓負載的 GND 浮動，I/O 會亂灌電）。高邊有兩派做法：

  • P-MOS 派（簡單）：P-MOS source 接電源，gate 拉到 GND 就開、拉到電源就關——驅動電壓都是現成的，一顆電阻一顆小訊號管就搞定。代價：P-MOS 天生 Rds(on) 差、大電流時又貴又熱。
  • N-MOS 派（高效但麻煩）：N-MOS 便宜又低阻，但放在高邊時 source 接負載端——管子全開後 source ≈ 電源電壓，而 Vgs 還得再高出約 5～10V，也就是 gate 需要「比電源軌更高」的電壓。這個電壓憑空生不出來，得靠 bootstrap（自舉）電路或電荷泵去「疊」出來。

7.1 Bootstrap 的白話原理

bootstrap＝「趁低點充電、跟著水位墊高」：

  1. 當開關節點（N-MOS 的 source，即 buck 的 SW 節點）在低電位（0V）時，driver 的供電（如 5V）透過一顆 bootstrap 二極體把 bootstrap 電容 Cboot 充到約 5V。
  2. 要開上管時，driver 用 Cboot 這顆「隨身電池」去推 gate。管子一開、SW 節點被拉到 12V，Cboot 的負端跟著 SW 一起浮上去，正端就變成約 12＋5＝17V——gate 順利拿到比電源高 5V 的驅動電壓。
  3. 二極體此時反偏，把 17V 和 5V 供電隔開。每次 SW 回到低電位，Cboot 補一次電。
bootstrap 的天生限制

Cboot 是靠「SW 節點週期性回到低電位」來補電的，所以 bootstrap 不能撐 100% duty（上管永遠開著）——電容遲早漏光。需要長期恆開的高邊 N-MOS（如 load switch 型應用、電池開關），得改用電荷泵（charge pump）持續產生高於電源的 gate 電壓——很多整合式 load switch IC 和 e-fuse 內部就是 N-MOS＋電荷泵。

8. 數學推導：把直覺釘牢（整段可跳過，結論已在上面）

平方律模型（長通道近似，功率管實際偏離此式，但面試推導用它就對了）。定義過驅動電壓 Vov = Vgs − Vth，k = µnCox(W/L)：

線性區（Vds < Vov）：Id = k [ Vov·Vds − Vds²/2 ]

白話翻譯：Vds 很小時，第二項可忽略 → Id ≈ k·Vov·Vds，電流正比於電壓——這就是電阻，且 Rds = 1/(k·Vov)：gate 抬越高（Vov 越大），電阻越小。這解釋了「為什麼 Rds(on) 規格要標 Vgs 條件」。

飽和區（Vds ≥ Vov）：Id = (k/2)·Vov²·(1 + λVds)

白話翻譯：電流只由 Vov 決定（平方關係），跟 Vds 幾乎無關——這就是電流源。物理圖像：Vds 大到把通道靠 drain 端「掐斷」（pinch-off），之後再加 Vds 只是把掐斷點稍微往 source 挪，電流不再增加。λ 那一項就是「掐斷點會挪」造成的微微上翹（通道長度調變），對應圖 2 飽和區曲線不完全水平。

兩區的分界怎麼來的？把線性區公式對 Vds 微分、令斜率為零，正好發生在 Vds = Vov——這就是圖 2 那條紅色拋物線（把 Vds = Vov 代回公式得 Id = (k/2)Vds²）。

放大用途再多推一步——轉導 gm（gate 每動 1V，電流動多少）：

gm = ∂Id/∂Vgs = k·Vov = 2Id/Vov

白話翻譯：gm 是「把手靈敏度」。共源放大器的增益 ≈ −gm·RD（或 −gm·ro），這也是第 5 節 Miller 效應裡那個 Av 的來源——放大越兇，Cgd 膨脹得越誇張。Miller plateau 電壓的公式 Vplateau ≈ Vth + Iload/gm 也從這裡來：plateau 期間管子是電流源，正好輸出負載電流，反解 Vgs 即得。

9. 實務案例：連回你的板子

9.1 NB 主機板的 load switch

典型場景：EC（嵌入式控制器）的 GPIO 控制某個子系統電源（WLAN、SSD、camera…）。標準電路：GPIO → 小訊號 NMOS（如 2N7002 等級）→ 拉低 P-MOS 的 gate → P-MOS 導通供電。三個實戰細節：

  • Inrush／soft-start：負載端往往掛著幾十～幾百 µF 的電容，P-MOS 瞬間全開＝對這堆電容短路充電，湧浪電流可達數安培，會把上游電源拉凹（板上其他軌跟著抖）。對策：gate 上加 RC 延緩（利用 Miller 效應反過來幫你：Cgd 上額外並一顆小電容，讓 drain 電壓斜率受控）——所以「Miller 是敵是友」看場合。整合式 load switch IC 直接內建 slew-rate 控制，就是把這件事做進去。
  • Vgs 絕對最大值：P-MOS 的 |Vgs| max 常見約 ±8V、±12V、±20V。source 接 19V adapter 軌、gate 直接拉到 GND → Vgs = −19V，超過 ±12V 的管子直接打穿氧化層。對策：gate–source 間加齊納或用電阻分壓箝位。這是 NB 板上真實燒板案例的常客。
  • 關斷也有學問：關斷後負載端電容上的殘壓怎麼放掉？很多 load switch IC 有 output discharge 功能（內建小 NMOS 對地放電），確保 power cycle 時序乾淨——camera 模組尤其在意這個（見 9.3）。

9.2 電源切換：adapter vs 電池

NB 的經典題：19V adapter 和電池兩路電源擇一供電。為什麼每一路都要 兩顆 MOSFET back-to-back？因為單顆管子的 body diode 會讓「關斷」名存實亡：adapter 這路關了，若電池電壓比 adapter 端高，電流照樣從 body diode 倒灌。兩顆背對背（共 source），兩顆 body diode 一顆朝左一顆朝右，任何方向都有一顆在擋，才是真正的雙向斷開。理想二極體控制器（ideal diode controller）＋N-MOS 的組合則進一步把「二極體 OR」的 0.5V 壓降換成 mΩ 級的 MOSFET，效率高很多。

9.3 鏡頭模組電源 gating

camera 模組通常有 2～4 軌（如 AVDD 約 2.8V、DVDD 約 1.05/1.2V、IOVDD 約 1.8V，依 sensor 而定），sensor datasheet 對上電／斷電順序與斜率有嚴格要求。這裡的 MOSFET 考點：

  • 時序由誰保證：PMIC 或分立 load switch＋EC 時序控制。每一軌一顆 load switch，enable 順序照 sensor spec（常見 IOVDD → AVDD → DVDD → MCLK，以實際 datasheet 為準）。
  • 斷電要放電：若斷電後某軌殘壓透過 sensor 內部 ESD 二極體倒灌到別軌，可能造成 latch-up 或下次上電時序違規——所以選有 discharge 功能的 load switch，或外加放電電阻。
  • 漏電流＝待機功耗：camera 大部分時間是關的，load switch 的關斷漏電（Ioff）直接算進待機電流預算，挑料時要看這個常被忽略的欄位（好料約 µA 級以下）。
  • 雜訊敏感：AVDD 是類比軌，load switch 的 Rds(on) 串在路徑上，模組工作電流變動會在上面產生壓差波動——Rds(on) 太大時等於在 AVDD 上疊了雜訊源，影像上可能看到條紋。這是「Rds(on) 不只關乎發熱」的好例子。

9.4 Datasheet 閱讀指南：SOA 與熱

白話版

SOA（Safe Operating Area，安全工作區）是一張「這顆管子在什麼電壓×電流×時間組合下不會死」的地圖，橫軸 Vds、縱軸 Id（雙對數）。看圖口訣：越往右上越危險，脈衝越短、允許範圍越大（100 µs 的線比 DC 的線高得多——短痛可以忍，久了會死）。

  • SOA 的四條邊界：左上被 Rds(on) 線切掉（電阻決定了小 Vds 時電流上限）、上邊是最大電流（打線／封裝限制）、右邊是 Vds 崩潰電壓、中間斜線是功率（熱）限制。現代溝槽式功率管還會多一段熱不穩定區（Spirito 區）：在高 Vds＋中等電流的「線性模式」下，局部熱點會正回饋惡化——這正是 load switch soft-start 拉太長、或用 MOSFET 做線性限流時最容易踩的死法：明明功率算起來沒超，管子還是燒了，因為 DC SOA 在那個區域比你想的小很多。
  • 熱阻三兄弟：RθJC（junction 到 case）、RθJA（junction 到環境，強烈依賴 PCB 銅箔面積——datasheet 標的往往是「1 inch² 2oz 銅」之類的理想條件，你的板子未必有）、Zθ（瞬態熱阻抗，算脈衝功率用）。估算式：TJ = TA + P × RθJA，算出來要留餘裕（一般設計目標 TJ 不超過 max 的約 80%）。
  • 降額思維：Vds max 對 ringing 尖峰也要成立（SW 節點的過衝要算進去）；Vgs max 是氧化層生死線，一次超標就可能永久損傷。

10. 動手練習與詳解

拿紙筆算，算完再展開詳解。

練習 1：一顆 NMOS，Vth = 2V。(a) Vgs = 5V、Vds = 0.2V 在哪一區？(b) Vgs = 5V、Vds = 8V 呢？(c) Vgs = 1.5V、Vds = 8V 呢？各自像什麼元件？

解：先算 Vov = Vgs − Vth。

(a) Vov = 3V，Vds = 0.2V < 3V → 線性區，像一顆小電阻（開關 ON 態）。

(b) Vov = 3V，Vds = 8V ≥ 3V → 飽和區，像一顆由 Vgs 控制的電流源（放大區；若這是開關，代表它正卡在切換途中或被誤用，會很燙）。

(c) Vgs = 1.5V < Vth → 截止區，開路。Vds 多大都一樣（只剩漏電流）。

練習 2：5V 軌 load switch，負載 3A，選了 Rds(on) = 25 mΩ（@Vgs=4.5V）的 P-MOS。(a) 導通損耗與壓降？(b) 若板上只有 RθJA ≈ 120 °C/W 的散熱條件、環境 60°C，TJ 大約多少？可以接受嗎？

解：

(a) P = I²R = 3² × 0.025 = 0.225 W；壓降 V = IR = 75 mV（5V 軌的 1.5%，通常可接受，但若下游還有 DC-DC 對輸入敏感就要算進預算）。

(b) TJ = 60 + 0.225 × 120 = 60 + 27 = 約 87°C。對 TJ(max) = 150°C 的料，餘裕足夠。但注意兩件事：Rds(on) 在 87°C 會比 25°C spec 高（迭代估算約再多三成，P 升到約 0.29W、TJ 約 95°C，收斂即可）；以及 datasheet 的 120 °C/W 對應的銅箔面積你的 layout 要真的給得出來。

練習 3：buck 的上管 N-MOS，Qgd = 6 nC，gate driver 在 plateau 期間能提供約 1A。(a) plateau 大約多長？(b) 若此期間 Vds 從 12V 掃到 0、負載電流 5A、fsw = 500 kHz，這段造成的開關損耗（單邊）約多少？

解：

(a) tplateau ≈ Qgd/Idrv = 6 nC / 1A = 6 ns。

(b) 用三角形近似：E ≈ ½ × V × I × t = ½ × 12 × 5 × 6n = 180 nJ；P = E × fsw = 180n × 500k = 0.09 W（只算電壓下降段的單邊，實際還要加電流換相段、關斷段與 Coss 損耗）。看見槓桿了嗎：driver 電流若只有 0.1A，plateau 變 60 ns、這一項直接變約 0.9W——driver 強度直接換算成效率。

練習 4（電路判讀）：P-MOS 高邊開關，source 接 19V，gate 經 100kΩ 上拉到 19V，另有一顆小 NMOS 可把 gate 拉到 GND。此 P-MOS 的 Vgs(max) = ±12V。這個電路有什麼問題？怎麼修？

解：小 NMOS 導通時，P-MOS 的 Vgs = 0 − 19 = −19V，超過 ±12V 絕對最大值，gate 氧化層可能被打穿（就算沒立刻死，也是可靠度未爆彈）。修法（擇一或併用）：

  • gate–source 之間並一顆約 10V 齊納（陰極朝 source），把 |Vgs| 箝在安全值；
  • 把「拉到 GND」改成電阻分壓（例如 gate 經 100k 上拉到 19V、下拉腳串 100k 再進 NMOS → gate 只被拉到約 9.5V，Vgs ≈ −9.5V）；
  • 換 Vgs(max) = ±20V 或 ±25V 的料。

順帶檢查：100kΩ 上拉＋gate 電容（Ciss 假設約 1 nF）→ 關斷時間常數約 100 µs，關得很慢；若此軌需要快速關斷（如過流保護路徑）就要改小電阻或加主動拉高電路。

練習 5（觀念題）：為什麼電池與 adapter 的電源切換每一路要用兩顆 back-to-back MOSFET，而普通 load switch 一顆就夠？

解：關鍵是 body diode 的方向、以及關斷時兩端誰高誰低。普通 load switch：關斷時上游（電源）永遠比下游（放完電的負載）高，body diode 方向被設計成反偏（P-MOS 高邊：S 接電源、D 接負載，body diode 陽極在 D），單顆就擋得住。電源切換：關斷的那一路，兩端誰高誰低會變（電池電壓可能高於或低於 adapter 端），單顆管子的 body diode 總有一個方向擋不住 → 倒灌。兩顆 back-to-back 讓兩顆 body diode 方向相反，任一極性都有一顆反偏在擋，形成真正的雙向阻斷。

11. 面試怎麼考

先用英文口頭回答，再展開對照。

Q1: "You're driving a power MOSFET with a weak GPIO and it's overheating even though the load current is well within spec. Walk me through what's happening and how you'd fix it."

參考答案骨架：Two failure mechanisms come to mind, both related to gate drive. First, the GPIO voltage may be too low: the datasheet threshold voltage only marks where the channel barely starts to conduct, but the rated Rds(on) requires several volts of overdrive. If I drive a device specified at Vgs = 10V with a 1.8V GPIO, the FET sits half-on with maybe ten times the expected on-resistance, and conduction loss explodes. Second, even if the amplitude is fine, a weak GPIO sources only a few milliamps, so each transition drags slowly through the Miller plateau — during that plateau the FET is in saturation with high Vds and full load current simultaneously, so every switching event dumps significant energy. Fixes: use a logic-level FET matched to my gate voltage, add a proper gate driver to shorten the plateau, or if it's a slow load switch, accept slow edges but verify the operating point stays inside the DC safe operating area, since linear-mode operation can violate SOA even at modest power.

加分點：主動提「I'd probe Vgs and look for the plateau on a scope — its length tells me the effective drive current, and its height tells me the operating current via gm.」展示你會從波形反推物理。

Q2: "Why do buck converters use an N-MOSFET for the high-side switch and how does the gate get driven above the input rail?"

參考答案骨架：N-channel devices have roughly two to three times better electron mobility than p-channel, so for the same Rds(on) they're smaller and cheaper — at buck currents that matters a lot. The catch is that a high-side NMOS has its source on the switch node, so to enhance it fully the gate must be driven several volts above the input rail. The standard solution is a bootstrap circuit: while the low-side FET conducts and the switch node sits near ground, a bootstrap capacitor charges to the driver supply through a diode; when the high-side turns on, the switch node flies up to Vin and the capacitor rides on top of it, giving the driver a floating supply of roughly Vin plus 5V to drive the gate. The limitation is that the capacitor only refreshes when the switch node returns low, so bootstrap can't support 100% duty cycle — controllers either limit maximum duty or add a charge pump for that case.

考點：測你是否理解「Vgs 是相對 source」這個根本觀念，以及 bootstrap 的充電路徑與 duty 限制。答得出「refresh 依賴 SW 回低電位」就贏過大多數人。

12. 今日 Anki 卡片

Q1：MOSFET 三大工作區的條件與等效元件？（NMOS）

A1：截止（Vgs<Vth）＝開路；線性/三極體區（Vgs>Vth 且 Vds<Vgs−Vth）＝可調電阻，開關 ON 態住這裡；飽和區（Vds≥Vgs−Vth）＝Vgs 控制的電流源，放大用、切換過渡時路過。注意與 BJT 的「飽和」意義相反。

Q2：Miller plateau 是什麼？長度與高度由什麼決定？

A2：開關切換時 gate 電壓暫停爬升的平台——driver 電流全部灌入被電壓增益放大的 Cgd（Crss），用來擺動 drain 電壓。長度 ≈ Qgd/Idrv；高度 ≈ Vth + Iload/gm。plateau 期間 Vds、Id 同時大，是開關損耗主要來源。

Q3：導通損耗 vs 開關損耗公式與取捨？

A3：Pcond=Irms²Rds(on)D（與頻率無關）；Psw≈½VI(ton+toff)fsw（正比頻率）。低 Rds(on)↔大 Qg，同製程 R×Q 近似常數（FOM）。慢開關挑低 R，快開關求平衡。

Q4：為什麼電源切換要 back-to-back 兩顆 MOSFET？

A4：單顆 MOSFET 的 body diode 使它只能單向阻斷；電源切換時關斷路徑兩端極性會反轉，必須兩顆背對背（共 source 或共 drain）讓兩顆 body diode 反向互擋，才能雙向阻斷防倒灌。

Q5：N-MOS 高邊為什麼需要 bootstrap？限制是什麼？

A5：高邊 N-MOS 全開後 source ≈ 輸入電壓，Vgs 需再高約 5～10V，即 gate 要高於電源軌。bootstrap 電容趁 SW 節點在低電位時充電，SW 升高時「疊」在其上提供浮動驅動電源。限制：需 SW 週期性回低電位補電 → 不支援 100% duty，恆開場合改用電荷泵。
