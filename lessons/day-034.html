PCB 通道本身是一個黑盒子。我們無法直接進去量電容、電感，但可以給它輸入、看輸出，根據輸入輸出的關係倒推裡面的病——這就是 S 參數（散射參數，Scattering Parameters）的工作。它是 SI 工程師必須會讀的「通道體檢報告」。讀完今天，你要能：

  1. 明白 S 參數是什麼、為什麼叫「散射」：反射和穿透——連回 Day 6 的反射係數 ρ、Day 9–14 的時域反射量測（TDR），看到它們是S 參數在單一時刻的一個「快照」

  3. 把 Day 25–26 學過的「損耗曲線」（IL vs 頻率），與 S21 的頻率響應對應起來——它們是同一份資料的不同呈現方式
  4. 直觀理解「IL 曲線上的凹陷」（insertion loss 下凹）對應什麼電路病——stub 諧振（Day 11）、via 阻抗反跳、串擾影響等
  5. 會看 dB 尺度與線性尺度互換、理解為什麼 dB 尺度在頻寬寬的東西上最好用
  6. 認識單端 2-port 的核心三式（反射係數 ρ、傳輸係數 τ、與能量守恆 |S11|² + |S21|² = 1 理想情況下成立），為週 13–14 的差動與 mixed-mode 預留位子

0. 前情提要：從時域反射看，到頻域掃描

過去五週學過三種不同「姿勢」看同一件事：

  • Day 6（週 1）：訊號在傳輸線末端遇到不同特性阻抗，會反射回去。反射大小用反射係數 ρ = (Z − Z0)/(Z + Z0) 量化。
  • Day 9–14（週 3）：時域反射量測（TDR）——在傳輸線上打入步進波，根據反回來的波形判讀每個位置的阻抗。是「一根線上從頭掃到尾，同一時刻看全部位置」。
  • Day 25–26（週 5）：損耗（insertion loss）——訊號通過一段傳輸線，不同頻率的衰減不同，用 IL(f) 曲線描述。

S 參數把這三種串起來。它用頻域掃描回答：「如果我在這個黑盒子的輸入端注入一個特定頻率的弦波，輸出會怎樣？」——掃遍所有頻率，就得到完整的「通道體檢報告」。

白話版：通道是個黑盒子，但可以會診

想像 PCB 上的高速訊號通道像一條黑盒子水管：看不見裡面有沒有積垢、轉折幾次、管徑的不連續在哪。但醫生可以從管口打進去染料水，根據哪些頻率的染料進得去、哪些進不去、進去的又反出來多少，推斷管子裡面的問題。S 參數就是這份體檢報告：它用數字和曲線告訴你，對於不同的頻率——有多少信號被反射回去（S11）、有多少穿透出來（S21）。工程師根據報告的形狀（尖峰、下凹、平坦），判斷是哪種病：是終端阻抗不匹配（S11 峰值高）？是中途有諧振（S21 凹陷）？是整體損耗過大（S21 向下滑）？同一份資料，用線性尺度看細節，用 dB 尺度看全景——就像同一條 X 光片，近看能看清楚鬆散的牙齒，遠看能看出整體骨質疏鬆。

1. 什麼是 S 參數（散射參數）

1.1 定義：散射＝反射＋穿透

「散射」就是訊號在遇到不連續或失配時，會分成兩部分：有些反射回去，有些穿透過去。S 參數用四個複數來描述一個雙端口（2-port）系統的散射行為：

S11 = 反射係數（port 1）｜S12 = 反向傳輸係數（port 2→port 1）
S21 = 正向傳輸係數（port 1→port 2）｜S22 = 反射係數（port 2）

單端傳輸線的理想情況（無損、終端匹配）：
|S11| = |S22| = 0（無反射）　｜　|S21| = |S12| = 1（全穿透，不損耗）

能量守恆（理想無損系統）：|S11|² + |S21|² = 1

白話翻譯：S 參數是複數（有大小與相位），通常用大小和相位分開報告。大小告訴你「反射或穿透有多少」，相位告訴你「相對於輸入，延遲或超前多少」。SI 工程師 90% 的時間只關心大小（幅值），相位留給天線工程師。能量守恆那條式子的意思是：進來 100% 的信號，反射出去 x%，就有 (100−x)% 穿透出去（理想無損時）；如果算出來反射 30%、穿透也 30%，那你的量測系統或計算有問題。

1.2 這三種「看法」其實在講同一件事

1.3 與傳輸線理論的橋樑

回想 Day 2 與 Day 6 的基本式：

反射係數：ρ = (Z_L − Z0)/(Z_L + Z0)　　　　傳輸係數：τ = 2Z_L/(Z_L + Z0)

若訊號完全無損、線性系統：
|ρ|² + |τ|² ≠ 1　（因為 τ 是電壓比，功率比須考慮阻抗）
正確的能量關係：反射功率 + 穿透功率 = 入射功率

白話翻譯：S 參數是單位電壓反射係數和穿透係數，直接對應 Day 6 講的 ρ 和 τ。但要注意單位：ρ 和 τ 是電壓比，S 參數在 50 Ω 系統下有時也用 50 Ω 的「偽」功率比表示。實務上工程師只要記得：S11 高 → 反射多 → 阻抗失配；S21 低 → 穿透少 → 損耗大或有諧振。

2. S11 與反射：通道的「終端病」

白話版：鏡子 vs 黑洞

把 S11 想成「這段通道的反射程度」——S11 = 0 時像黑色布料（訊號進去就吸收，沒有反射），S11 = 1 時像完美鏡子（訊號全反射回去）。在 DUT 末端貼一個不等於 50 Ω 的東西（比如未端接的 IC pad，或一個 100 Ω 的終端電阻），訊號進去一部分反射出來，就會在 S11 的頻率響應上看到「峰值」或「凹陷」。如果是阻抗反跳（via 附近突然變粗），就會看到高頻的小尖峰。工程師根據尖峰的頻率，往往能反推是什麼東西造成的。

S11 定義在 port 1 測量的反射，通常用來量測被測物（DUT）的入阻抗。若 DUT 是一段傳輸線，S11 主要取決於終端阻抗：

  • 終端完美匹配（Z_L = Z0）：S11 ≈ 0（無反射）
  • 終端開路（Z_L = ∞）或短路（Z_L = 0）：S11 ≈ ±1（全反射）
  • 終端部分失配：S11 是 0 到 1 之間的數值，取決於失配程度

更重要的是，S11 的頻率響應形狀會洩露通道內部的結構：

  • 寬平的凸起（broad hump）：整段通道的特性阻抗有緩的變化（如 PCB 微帶線逐漸變細）
  • 尖銳的峰值（sharp spike）：某個特定頻率的諧振或諧波陷阱。比如 Day 11 的 stub 諧振：stub 長度對應的共鳴頻率上，反射會特別強
  • 高頻小波紋（ripple）：via 不連續、分層阻抗變化、或多層板平面之間的耦合
Stub 諧振的反射係數（Day 11 復習）：
Z_stub = j·Z0·tan(βl)　（其中 β = 2π/λ、l 是 stub 長度）

當 βl = π/2 (或 3π/2、5π/2...)：tan 趨於無窮 → Z_stub 開路 → |S11| = 1
（即 l = λ/4、3λ/4、5λ/4...）

3. S21 與損耗：通道的「健康」

白話版：聽筒的音量與清晰度

S21 就是通道的「穿透率」——訊號有多少進得來。S21 = 1 時信號毫髮無損，S21 = 0.5 時只有一半穿透得了。在實務上，S21 通常用「插入損耗」（insertion loss，IL）表示：IL = −20 log₁₀(|S21|) dB。一個 S21 = 0.5 的通道，IL = 6 dB（損失一半功率）；S21 = 0.9，IL ≈ 0.9 dB（損失不到一成）。

S21 的曲線形狀會告訴你通道有什麼毛病：③ 如果曲線整體向下傾斜（低頻 −1 dB、高頻 −6 dB），就是「頻率相關損耗」，來自導體損（skin effect，Day 25）和介質損；② 如果曲線光滑但某個頻率出現凹陷（dip），那通常是 stub 諧振的「反面」——該頻率能量被反射了，穿透下來的就少；③ 如果曲線上出現多個尖峰（不規則），那可能是多層板內的平面共鳴、或通道彎曲產生的「多路徑」干涉。

S21 與插入損耗的換算：
IL (dB) = −20 log₁₀(|S21|)　　　　或　　|S21| = 10^(−IL/20)

S21 幅值與功率的關係（50 Ω 系統）：
P_out / P_in = |S21|²　　　　（假設 S11 ≈ 0、無其他反射）

白話翻譯：IL 曲線就是 S21 的「負對數」。為什麼要用 dB？因為 S21 的變化範圍很寬（0.99 到 0.1 都是常見的），線性尺度下很難看出細節——0.99 和 0.98 在曲線上看起來一樣，但實務上都是「損耗小於 0.1 dB」，計算起來是一樣的。用 dB 後，−0.08 dB 和 −0.16 dB 在圖上就能清楚看出差異。所以實務上拿到 S 參數檔，S21 都是用 dB 單位給出（稱 S21(dB) 或 S21_mag）。

3.1 「IL 曲線凹陷」的診斷學

根據凹陷的形狀與頻率，可以倒推病因：

IL 曲線特徵 可能的原因 所在課程
尖銳單峰凹陷（某個頻率穿透少） Stub 諧振（Day 11）或 via 轉角的不連續諧振 Day 11, 15
多個規則凹陷（一個頻率間隔重複） 多層板平面之間的平行板耦合共鳴，或分岔短線造成的多路徑干涉 Day 8, 9
整體向下傾斜（低頻 0 dB、高頻 −10 dB） 導體損 + 介質損（skin effect），正常。但若斜率太陡（>−1 dB/GHz）要檢查線寬、層疊設計 Day 25, 26
低頻高於高頻，但有平臺（−0.5 dB 到 −2 dB 區間很平） 整條線的阻抗從低頻到某個頻率算匹配，超過那個頻率才損耗快升。通常是 RC 濾波或終端網路的效應 Day 10, 18

4. dB 尺度與線性尺度

白話版：地震儀與分貝王

線性尺度（0 到 1）像用尺子量長度——結論明確，但問題是：0.99 和 0.98 看起來沒區別，你無法判斷「損耗減了多少」。dB（分貝）尺度是對數，把小數值「放大」了——好比地震儀把極微弱的地動放大 1000 倍才看得出來。在 SI 工程：−0.1 dB 損耗是「很好」，−1 dB 是「可接受」，−6 dB 是「有問題」。用線性尺度分別是 0.989、0.891、0.501，毫無規律；用 dB 尺度就是「−0.1、−1、−6」，一眼看出劣化程度。

dB 與線性的互換：
S21(dB) = 20 log₁₀(|S21|)　　　　（電壓或場強）
P(dB) = 10 log₁₀(P/P_ref)　　　　（功率）

快速查表（20 log₁₀ 版，工程常用）：
|S21| = 1 → 0 dB　　　　0.9 → −0.9 dB　　　　0.7 → −3 dB　　　　0.5 → −6 dB
0.3 → −10 dB　　　　0.1 → −20 dB　　　　0.01 → −40 dB

5. 實務案例：NB 主機板的高速訊號通道診斷

場景：DDR5 時脈線路的 S 參數量測與診斷

筆記型電腦主機板上，DDR5 時脈從 PMIC 經過 15 cm 走線送到 DRAM，沿路要經過：電源平面之間的通孔（via）、過轉角、穿過磁珠濾波網路、最後到 DRAM 的 BGA ball。產線上量了一片板的 S 參數，發現：
① S11 在 800 MHz 和 2.4 GHz 各有一個尖峰（|S11| = 0.3）
② S21 整體向下傾斜，800 MHz 時 −1.5 dB、2.4 GHz 時 −4.2 dB
③ 在 1.6 GHz 出現一個尖銳凹陷（S21 掉到 −0.6 dB 而旁邊是 −1.2 dB）

工程師的診斷：① 800 MHz 尖峰 → 查 PCB 結構，發現有個 0.5 pF via 樁（via stub）附近阻抗不連續，λ/4 = (c/f)/4 ≈ 9 cm（走線長度）= stub 共鳴點；② 2.4 GHz 尖峰 → 可能是磁珠濾波網路的並聯諧振；③ 整體傾斜 → 正常的導體＋介質損；④ 1.6 GHz 凹陷 → 可能是同層相鄰走線的串擾（Day 4）造成的反向傳輸耦合。對策：加電源通孔接地、調整磁珠參數、加端接網路。

6. 單端 2-port 的核心三式（為差動預留位子）

白話版：「我會背三式，週 13 差動不用驚」

單端系統只有一個訊號線＋一個地。輸入端（port 1）和輸出端（port 2）各有一個反射係數（S11、S22），中間有正向（S21）與反向（S12）穿透。90% 的 SI 工作只用前三個——S11（輸入反射）、S21（正向損耗）、S22（輸出反射）。但在差動訊號（週 13）時，會多出「同向」與「反向」的組合（called common-mode 與 differential-mode），S 參數矩陣會變成 4×4——但骨子裡還是在看「反射多不多、損耗大不大」，只是有兩組獨立頻率響應。今天記住單端的三式，下週就不會困惑。

單端 2-port 的四參數網路（其中 S12 與 S21 在無損對稱系統下相等）：
[b₁] [S11 S12] [a₁]
[b₂] = [S21 S22] [a₂]

其中 a₁ 是入射波、b₁ 是反射波、a₂ 是輸出口的反射進來、b₂ 是穿透出去的

能量守恆（無損時）：|S11|² + |S21|² = 1　（假設 port 2 完美終端）

7. 動手練習

練習 1：反射係數的 dB 換算（點開看詳解）

題目：某通道的 S11 在 500 MHz 測得 0.15（線性值）。請轉換成 dB 單位，並判斷失配程度。

詳解：

S11(dB) = 20 log₁₀(0.15) = 20 × (−0.824) ≈ −16.5 dB

失配判斷：|S11| = 0.15 意味著 15% 的訊號被反射回去，相當於反射係數 ρ = 0.15。根據 Day 6 的公式：

ρ = (Z_L − Z0)/(Z_L + Z0) = 0.15
→ Z_L − Z0 = 0.15(Z_L + Z0)
→ Z_L(1 − 0.15) = Z0(1 + 0.15)
→ Z_L ≈ 1.35 Z0 ≈ 67.5 Ω（假設 Z0 = 50 Ω）

終端阻抗約 68 Ω，相對 50 Ω 失配 35%——小信號場景（如示波器探棒終端）算可接受，高速訊號場景（如 LVDS）就不行。

工程判斷：若這是要送給 DRAM 的 DDR5 時脈，−16.5 dB 反射算「合格」（一般要求 <−10 dB）；若這是 LVDS 差動對，就要檢查終端網路了。

練習 2：S21 與插入損耗的轉換（點開看詳解）

題目：某 PCB 走線的 S21 在 2 GHz 測得 0.89（線性值）。(a) 轉換成 dB；(b) 換算成功率損耗百分比。

詳解：

(a) S21(dB) = 20 log₁₀(0.89) ≈ −1.0 dB（−20 log 版本）

插入損耗 IL = −S21(dB) = +1.0 dB（通常 IL 用正數表示損失）

(b) 功率損耗：

P_out/P_in = |S21|² = 0.89² ≈ 0.792
損耗功率百分比 = 1 − 0.792 = 20.8%（約 21% 的功率在這段線路被耗散）

工程判斷：2 GHz 時 1.0 dB 損耗是正常的（高速訊號線的典型值）。但若走線長度只有 5 cm，這個損耗就偏高，可能需要檢查：① 微帶線微距（trace width）是否太窄；② 層疊是否選錯（介質損耗特別高的材料）；③ 沿路有沒有 via 或彎曲增加損耗。

練習 3：Stub 諧振的診斷（點開看詳解）

題目：某 NB 主機板的 DDR 訊號，在 S11 與 S21 曲線上看到一個尖銳的峰值 / 凹陷組合，正好在 1.2 GHz。估計這是哪種元件造成的失配？（假設 Dk = 4、訊號速度 c_eff ≈ 1.5 × 10⁸ m/s）

詳解：

尖銳峰值 + 凹陷 = Stub 諧振的標誌（Day 11）。Stub λ/4 共鳴：

λ = c_eff / f = (1.5 × 10⁸) / (1.2 × 10⁹) ≈ 0.125 m = 125 mm
l_stub = λ/4 ≈ 31 mm

31 mm stub 是什麼東西？可能是：

  • PCB 上 DDR 終端網路的一條短走線尚未接地
  • BGA ball 或 connector pin 的引線長度造成
  • via 樁（via stub）——從訊號層打孔下來，上面還留著孔的「尾巴」

對策：檢查 1.2 GHz 附近有沒有看起來奇怪的短走線；如果是 via 樁，改用「背鑽」（via 從另一側鑽開）或「接地 via」貼住。

練習 4：多通道比較與故障排查（點開看詳解）

題目：某個連接器有 4 對高速通道，量了 S21 曲線，結果三條一致（都是 −1.2 dB @2 GHz），但第四條異常地高（−0.3 dB @2 GHz）。怎麼判斷是什麼出問題？

詳解：

三條正常、一條偏高（穿透偏多，即損耗偏少），可能的原因：

  • 最可能：第四條通道根本沒有經過濾波網路或某個衰減元件（而其他三條都經過）。檢查原理圖，看第四條走線的路由是否不同。
  • 次可能：第四條在 PCB 上走在更高的層（介電常數更低的層間），損耗自然較少。查層疊和高度。
  • 測量誤差：量測時連接器對接不良（比如第四條接觸不好，其實是開路啊，為什麼還有 −0.3 dB 而不是掛掉）——不太可能，除非你的網路分析儀壞了。

行動：先驗證三條「正常的」線路是不是真的一致（檢查重複性）；然後跟第四條比較原理圖和 PCB layout；測過多片看是單片問題還是普遍現象。

8. 面試怎麼考

英文題目 + 參考答案

Question 1: "You are given S-parameter data for a DDR5 clock trace on an NB motherboard. The S11 shows a sharp dip at 1.6 GHz, and S21 has a notch at the same frequency. What could be the root cause, and how would you fix it?"

Reference answer: A sharp dip in S11 combined with a notch in S21 at a specific frequency is typically caused by a stub resonance or a via discontinuity. At 1.6 GHz, the quarter-wave length is roughly: λ/4 = c_eff/(4f) ≈ (1.5×10⁸ m/s) / (4 × 1.6×10⁹ Hz) ≈ 23 mm. This suggests a stub or via pin of that length is resonating. To fix: (1) Use via-in-pad with copper plating to bury the stub; (2) Add a short stitching via to ground immediately after the stub to kill the resonance; (3) Check if there's an unterminated branch in the circuit. The diagnostic value of S-parameters here is that the frequency of the dip directly reveals the physical length causing the problem.

Question 2: "Your network analyzer shows S21 = −0.8 dB @ 2 GHz for a board-to-board connector. Is this acceptable for a 5 Gbps signal? What other information would you need to make a decision?"

Reference answer: To determine if −0.8 dB is acceptable, we need to know: (1) The total channel budget (how much loss can the receiver tolerate before losing eye margin); (2) The data rate's required bandwidth (5 Gbps NRZ typically needs 2.5 GHz bandwidth; at 2 GHz we're already in the high-loss region); (3) Whether this loss is linear or frequency-dependent (if loss keeps climbing beyond 2 GHz, high-frequency content will suffer more); (4) Receiver equalizer capability (some receivers have on-die equalization that can compensate ~5–10 dB of loss). The S21 curve shape matters more than a single point: a smooth roll-off is recoverable, but sharp dips or ripples indicate resonances that equalization cannot fix easily.

9. 今日 Anki 卡片

卡 1（定義）：
正面：S11、S21、S22 分別代表什麼？
背面：S11 = 反射係數（port 1）｜ S21 = 正向穿透係數 ｜ S22 = 反射係數（port 2）。在單端系統，SI 工程師主要看 S11（終端失配）和 S21（損耗）。

卡 2（換算）：
正面：S21(dB) 與線性 S21 的關係式是什麼？
背面：S21(dB) = 20 log₁₀(|S21|)。記住快速查表：S21=0.9 → −0.9 dB；0.7 → −3 dB；0.5 → −6 dB。

卡 3（診斷）：
正面：S21 曲線上看到一個「尖銳的下凹」（notch），而周邊頻率正常，這表示什麼？
背面：某個頻率的諧振或共鳴（通常是 stub 或 via 的 λ/4 共鳴）。該頻率的能量被反射出去，所以穿透下來少。可根據凹陷頻率 f 反推 stub 長度 l ≈ c_eff/(4f)。

卡 4（連結）：
正面：Day 6 的反射係數 ρ 與 S11 有什麼關係？
背面：S11 就是 ρ（在匹配的系統中，或相當於終端的反射係數）。Day 6 是「一個固定頻率算一次 ρ」；Day 34 S11 是「掃遍所有頻率，每個頻率都有一個 ρ」——背後原理相同，只是 S 參數把頻率依賴性完整呈現出來。

卡 5（應用）：
正面：在 NB 主機板 DDR5 設計時，為什麼要量 S 參數而不只量 TDR？
背面：TDR 看通道的物理結構（有沒有 via 凹陷、阻抗有沒有突變），但看不出「頻率相關損耗」和「共鳴陷阱」。S 參數的頻域掃描能抓住 stub 諧振、磁珠濾波網路的並聯共鳴等頻率現象。TDR + S 參數一起用，才能全景診斷。
